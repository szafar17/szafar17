- **[property-scout](https://github.com/szafar17/property-scout)**: daily listing pipeline with adapters for two MLS APIs (RESO Web API, RETS). It dedupes and enriches listings and scores each one 0 to 100, with Claude reading the remarks. An MCP server lets AI agents query listings and test scoring weights.
